# WeFlow Time releases

Public distribution channel for **WeFlow Time** desktop updates (macOS Apple Silicon + Intel).

Source code stays private in [`wef0rm/weflow-time`](https://github.com/wef0rm/weflow-time).  
This repo only holds GitHub Releases with signed installers and `latest.json` for the in-app updater.

| Arch | Updater platform key |
|------|----------------------|
| Apple Silicon (M-series) | `darwin-aarch64` |
| Intel | `darwin-x86_64` |

Do not commit source or signing private keys here.
